# Retired workflows

The pjws workflow was retired on 2026-09-21. Its source is [archived in place](../workflows/pjws/ARCHIVED.md), disabled, and no longer built. The orchestrator source remains at `~/Code/pjws` for reference, and old project data is retained. Use [New Workspace](../workflows/new-workspace/README.md) for new desktops and windows.

The archived zip is a historical build, not an installation recommendation. Tests retained under `tests/pjws_*` document the previous frontend behavior.
